# recipe-catalog-deploy

Deployment configuration for the Recipe Catalog project.

## Services

- `food-history-api` — REST API ([repo](https://github.com/zglossip/food-history-api))
- `recipe-scanner` — OCR/LLM recipe extraction service ([repo](https://github.com/zglossip/recipe-scanner))
- `postgres` — database for the API

## Deployment target

Single Windows desktop machine on LAN. Images pulled from GHCR.
